# 04 AI 辅助使用说明

## 1. AI 使用范围

本项目在 AI 助手辅助下完成，AI 主要承担：

- 需求拆解：将题目要求转化为验收点与目录结构。
- 代码骨架生成：数据层、四个工具、决策模型、Agent 循环与 CLI。
- 测试与文档：单元测试用例、Trace 核对、文档撰写。
- 问题定位：分析失败注入与重规划逻辑中的设计问题。

## 2. 个人理解与验证

候选人对以下设计进行了确认与理解：

- ReAct 循环：模型选择动作 → 执行工具 → 观察结果 → 调整或结束。
- 重规划：超预算或工具失败时切换方案，并保留已成功步骤。
- 幂等：同一任务重复保存不产生新方案。
- 红线：失败步骤不记为成功，不虚构方案。

## 3. 开发中的关键修正

在场景验证过程中发现并修正了一个设计问题：

- **问题**：最初的失败注入为「持续失败」，导致替代方案下同一工具仍失败，
  无法体现题目要求的「注入一次失败后失败续跑」。
- **修正**：在 `DataStore` 增加 `failed_tool_once` 一次性失败机制，首次
  调用失败后自动恢复；Agent 切换方案并复用素材检索结果，最终成功。
- **验证**：修正后 `trace_T01_tool_fail_recover.json` 显示 8 步完成，
  对应测试 `test_fail_once_then_recover` 通过。

## 4. 验证结论

- 9 个单元测试全部通过。
- 8 份场景 Trace 均由真实运行生成，可复现。
- 所有命令均可在项目根目录直接复制运行。
